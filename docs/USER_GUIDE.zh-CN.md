# Vellum 使用文档

简体中文 | [English](USER_GUIDE.md)

Vellum 面向需要长时间阅读 PDF 的用户：论文、手册、资料、长文档都适合。它的核心思路很简单：尽量让双手留在键盘上，让页面移动顺滑，让常用阅读动作足够靠近。

![Vellum 阅读界面截图占位](images/vellum-reader.png)

## 1. 开始阅读

打开 Vellum 后，可以在空白阅读页选择 PDF，也可以按 `o` 在当前标签页打开文件。

如果想一次打开多个 PDF，按 `O`，选择的每个文件都会进入独立标签页。

常用文件和标签页按键：

| 按键 | 功能 |
| --- | --- |
| `o` | 在当前标签页打开 PDF |
| `O` | 在新标签页打开 PDF |
| `x` | 关闭当前标签页 |
| `X` | 恢复最近关闭的 PDF |
| `]` / `[` | 下一个 / 上一个标签页 |
| `L` / `H` | 下一个 / 上一个标签页 |
| `gt` / `gT` | 下一个 / 上一个标签页 |
| `Command-O` | 打开 PDF |
| `Command-W` | 关闭标签页 |
| `Command-]` / `Command-[` | 下一个 / 上一个标签页 |

## 2. 在 PDF 中移动

Vellum 使用 Vim 风格的阅读按键。短按移动一点，按住移动键会持续平滑移动。

| 按键 | 功能 |
| --- | --- |
| `j` / `k` | 向下 / 向上平滑滚动 |
| `d` / `u` | 大幅向下 / 向上平滑滚动 |
| `h` / `l` | 向左 / 向右横向滚动 |
| `Space` / `f` | 向后翻一页 |
| `b` | 向前翻一页 |
| `gg` | 跳到第一页 |
| `G` | 跳到最后一页 |
| `[num]G` | 跳到指定页，例如 `12G` |
| `Control-O` | 后退到上一个阅读位置 |
| `Control-I` | 前进到下一个阅读位置 |

阅读历史会记录普通页面跳转和目录跳转，所以你可以放心探索文档，再快速回到原位置。

## 3. 缩放和适配

当 PDF 太小、太宽，或者需要按整页阅读时，可以使用缩放按键。

| 按键 | 功能 |
| --- | --- |
| `=` / `+` | 放大 |
| `-` | 缩小 |
| `0` | 适合整页 |
| `z` | 适合宽度 |

按住 `=` 或 `-` 可以连续缩放。

## 4. 使用目录侧边栏

按 `Tab` 或 `t` 显示或隐藏目录侧边栏。目录获得焦点后，会使用自己的一组键盘行为。

![目录截图占位](images/vellum-outline-tabs.png)

| 按键 | 目录中的功能 |
| --- | --- |
| `j` / `k` | 向下 / 向上移动目录选中项 |
| `h` | 折叠选中项，或移动到父级 |
| `l` | 展开选中项 |
| `Enter` | 跳到选中的目录位置 |
| `Tab` | 隐藏目录侧边栏 |

提示：从目录跳转后，可以按 `Control-O` 回到之前的阅读位置。

## 5. 页面概览

短暂按住 `Tab` 可以打开页面概览。按住 `Tab` 时，用方向式按键选择附近页面，松开 `Tab` 后结束概览。

| 按键 | 页面概览中的功能 |
| --- | --- |
| 按住 `Tab` | 打开页面概览 |
| `h` / `l` | 上一页 / 下一页 |
| `k` / `j` | 上一行 / 下一行 |
| 松开 `Tab` | 在选中页面关闭页面概览 |

## 6. 搜索

按 `/` 打开搜索，输入关键词后按 `Enter` 确认。匹配结果会以高亮形式保留，Vellum 会记录当前活跃匹配项。

| 按键 | 功能 |
| --- | --- |
| `/` | 开始搜索 |
| `Enter` | 确认搜索关键词 |
| `Esc` | 取消搜索或清理可见搜索状态 |
| `n` | 跳到下一个匹配 |
| `N` | 跳到上一个匹配 |
| `v` | 把当前匹配结果转成文本选择 |
| `y` | 在可用时复制当前搜索匹配 |

当你想对搜索结果进行高亮、复制或 AI 解释时，可以先按 `v`，把它变成普通文本选择。

## 7. 选择文本

你可以先用鼠标或触控板选择文本，然后用键盘微调选择范围。

当存在文本选择时，一些移动键会从页面移动切换为选择范围移动：

| 按键 | 选中文本时的功能 |
| --- | --- |
| `h` / `l` | 向左 / 向右移动选择端点 |
| `j` / `k` | 按视觉行向下 / 向上移动选择端点 |
| `w` / `b` / `e` | 按单词移动选择端点 |
| `Esc` | 清除文本选择 |

这个模式适合在高亮、复制或 AI 解释之前，把选择范围调整得更准确。

## 8. 高亮和复制

标签栏里的高亮工具条可以选择当前高亮颜色。键盘高亮命令会使用当前选中的颜色。

| 按键 | 功能 |
| --- | --- |
| `m` | 高亮选中文本 |
| `c` | 切换高亮颜色 |
| `y` | 复制选中文本 |
| `d` | 当文本选择命中已有高亮时，删除该高亮 |

可用高亮颜色包括黄色、绿色、青色、紫色和粉色。

## 9. AI 解释

AI 解释是可选功能。使用前需要先在设置中配置 OpenAI 兼容服务。

![AI 解释截图占位](images/vellum-ai-explanation.png)

配置 AI：

1. 打开 Vellum 设置。
2. 进入 AI 标签页。
3. 填写 Base URL、API Key 和 Model。
4. 如果服务支持模型列表，可以点击 Fetch Models。
5. 点击 Test Connection 确认聊天接口可用。

阅读时使用 AI：

| 按键 | 功能 |
| --- | --- |
| `a` | 解释选中文本或选中的高亮 |
| `j` / `k` | 在 AI 解释内容中滚动 |
| `m` | 把解释对应的文本保存为高亮 |
| `c` | 在 AI 解释激活时切换高亮颜色 |
| `Esc` | 关闭解释 |

保存过的 AI 解释会附着在高亮上。以后悬停到带 AI 解释的高亮时，可以再次查看解释内容。

## 10. 设置和快捷键参考

打开设置可以访问：

- AI 服务配置。
- 连接诊断。
- 内置快捷键参考。

忘记按键时，设置里的快捷键参考是最快的查询入口。

## 11. 推荐阅读流程

1. 按 `o` 打开 PDF。
2. 按 `z` 进入适合宽度阅读。
3. 用 `j`、`k`、`d`、`u` 移动页面。
4. 如果文档有目录，用 `Tab` 打开目录浏览。
5. 用 `/` 搜索，再用 `n` 和 `N` 在匹配之间跳转。
6. 对活跃搜索结果按 `v`，可以把它转成普通文本选择。
7. 用 `m` 高亮重点，用 `y` 复制文本，用 `a` 请求 AI 解释。
8. 用 `Control-O` 和 `Control-I` 在阅读历史中后退或前进。

## 12. 常见问题

如果字母按键没有移动 PDF，先检查焦点是否在搜索框、设置页、目录侧边栏或 AI 解释窗口中。这些区域会使用自己的键盘行为。

如果 AI 解释失败，请检查设置中的 Base URL、API Key、模型名称和 Test Connection 结果。

如果目录侧边栏没有内容，通常是因为这个 PDF 文件本身没有内置目录。

如果搜索找不到预期文字，可能是 PDF 页面为扫描图，或文字编码方式无法被 PDFKit 稳定提取。
