# Vellum 使用文档

简体中文 | [English](USER_GUIDE.md) · [README](../README.zh-CN.md)

Vellum 是一款原生 macOS PDF 阅读器，支持键盘导航、沉浸画廊、可搜索的标签切换器、目录和高亮。要求 macOS 14 或更新版本，支持 Apple silicon 和 Intel Mac。

![Vellum 阅读界面](images/vellum-reader.png)

## 打开文件和管理标签页

从 [GitHub Releases](https://github.com/AbyssSkb/Vellum/releases/latest) 下载应用，打开磁盘映像，将 Vellum 拖入 Applications。启动后，可以从空白阅读页或文件选择器打开 PDF。

`o` 和 `Command-O` 遵循**设置 → 通用 → 默认打开方式**。初始默认替换当前标签页，也可以改为新标签页。`O` 始终在新标签页打开 PDF，支持一次选择多个文件。通过 Finder 打开的文件也会进入新标签页。

同一文件只保留一个标签页。再次打开时会选中已有标签；如果文件已在磁盘上更新，会在保护未保存批注之后重新读取最新内容。`X` 会从磁盘恢复最近关闭的 PDF。

| 按键 | 功能 |
| --- | --- |
| `o` / `Command-O` | 按配置的默认方式打开文件 |
| `O` | 在新标签页打开 PDF |
| `x` / `Command-W` | 关闭当前标签页 |
| `X` | 恢复最近关闭的 PDF |
| `H` / `L` | 上一个 / 下一个标签页 |
| `[` / `]` | 上一个 / 下一个标签页 |
| `gT` / `gt` | 在阅读区切换到上一个 / 下一个标签页 |
| `Command-[` / `Command-]` | 上一个 / 下一个标签页 |
| `T` | 打开可搜索的标签切换器 |

在标签切换器中，输入文件名片段筛选列表，用 `↑` / `↓` 选择结果，按 `Enter` 切换，按 `Esc` 取消。此时字母用于搜索输入。

长标题会在打开文件或切换到该标签时滚动一轮，也可以悬停再次查看。通用设置中的**恢复上次标签页**可在下次启动时恢复阅读会话，初始默认关闭。

## 导航和缩放

短按移动页面；按住滚动键或缩放键，会持续移动或缩放。

| 按键 | 阅读区中的功能 |
| --- | --- |
| `j` / `k` | 向下 / 向上平滑滚动 |
| `d` / `u` | 大幅向下 / 向上滚动 |
| `D` / `U` | 更大幅度向下 / 向上滚动 |
| `h` / `l` | 向左 / 向右横向滚动 |
| `Space` / `f` | 向后翻一页 |
| `b` | 向前翻一页 |
| `gg` / `G` | 第一页并贴合文档顶部 / 最后一页并贴合文档底部 |
| `[数字]G` | 跳到指定页，例如 `12G` |
| `Control-O` / `Control-I` | 在跳转历史中后退 / 前进 |
| `=` / `+` / `-` | 放大 / 缩小 |
| `0` | 适合整页 |
| `z` | 适合宽度 |

页面跳转和目录跳转都会进入跳转历史。数字页码按 PDF 中从 1 开始的页面位置计算。适配时保持页面比例：`z` 撑满阅读区宽度，`0` 保证整页可见。通用设置可以选择打开文件时适合宽度或适合整页。

## 浏览目录

按 `t` 显示或隐藏目录。打开时聚焦目录，并将浏览光标对齐到当前阅读章节；关闭时聚焦正文。短按不带修饰键的 `Tab` 在正文和目录之间切换焦点，目录隐藏时会先打开它。仅切换焦点会保留目录的显示状态和浏览光标。

选择条目后按 `Enter` 跳转并聚焦正文。目录中的 `Esc` 会先清除待完成的次数或命令前缀；没有待完成输入时，则回到正文焦点，目录仍然显示。也可以点击相应区域切换焦点。

当前阅读章节的标记与目录浏览光标相互独立。滚动时以阅读区域的水平中线判断当前章节，通常在章节标题越过这条线时更新。正文获得焦点时，进入另一个章节会让目录光标跟随该章节；目录获得焦点时，浏览光标、滚动位置和折叠状态由你控制，阅读章节标记可以独立更新。章节位于收起的分支内时，会标记最近的可见祖先；阅读不会自动展开目录。

![目录侧边栏和文件标签页](images/vellum-outline-tabs.png)

| 按键 | 目录获得焦点时的功能 |
| --- | --- |
| `j` / `k` 或 `↓` / `↑` | 下一个 / 上一个可见条目 |
| `h` 或 `←` | 关闭包含光标的一层折叠，等同于 `zc` |
| `l` 或 `→` | 打开包含光标的一层关闭折叠；没有可打开的折叠时向下移动一项 |
| `gg` / `G` 或 `Home` / `End` | 第一个 / 最后一个可见条目 |
| `[数字]G` / `[数字]gg` | 选择第几个可见条目 |
| `d` / `u` | 向下 / 向上移动半个目录视口 |
| `D` / `U`、`f` / `b`、`Page Down` / `Page Up` | 向下 / 向上移动一个视口 |
| `Space` | 向下移动一个视口 |
| `Enter` | 跳到选中条目的位置并聚焦正文 |
| `H` / `L` 或 `[` / `]` | 上一个 / 下一个文件 |
| `Control-O` / `Control-I` | 在 PDF 跳转历史中后退 / 前进 |
| `Tab` | 聚焦正文，目录仍然显示 |
| `Esc` | 清除待完成的次数或前缀，否则聚焦正文 |
| `t` | 关闭目录并聚焦正文 |

目录移动支持次数前缀：`10j` 从当前位置向下移动十个可见条目；`10G` 直接选择第十个可见条目。条目右侧的页码表示 PDF 跳转目标，不是目录条目的序号。

### 折叠目录

Vellum 使用 Vim 的折叠命令。按顺序输入按键，注意字母大小写。

| 命令 | 功能 |
| --- | --- |
| `zo` | 打开包含光标的一层关闭折叠 |
| `zc` | 关闭包含光标的最内层打开折叠 |
| `zO` | 打开包含光标的第一个关闭折叠及其所有后代 |
| `zC` | 关闭所有包含光标的折叠 |
| `zr` / `zm` | 增加 / 减少全局可见折叠层级 |
| `zR` / `zM` | 展开 / 折叠全部 |

次数放在 **`z` 前面**：`2zo` 最多打开两层包含光标的折叠，`2zc` 最多关闭两层，`2zr` / `2zm` 将全局层级增减两层。`zO`、`zC`、`zR`、`zM` 已经执行递归或全局操作，次数不会扩大其范围。

关闭包含光标的折叠后，应用仍记住光标原来的条目，即使可见选中项变成了祖先。接着按 `zo`，可以重新显露原来的条目。选中叶子条目时，`zc` 会关闭包含它的分支。局部折叠保留隐藏后代的展开状态；`zr`、`zm`、`zR`、`zM` 则对整个目录应用层级。切换文件时，每个打开的标签页会记住自己的目录状态。

另一组按键是 `Option-→` / `Option-←`，递归展开 / 折叠当前分支。选中叶子时使用其父分支。再加 `Shift`，会应用到整个目录。

## 使用沉浸画廊

在正文或目录中长按不带修饰键的 `Tab` 打开画廊。画廊放大展示选中页面，并呈现相邻页面，与正文保持连续的视觉关系。

![沉浸画廊](images/vellum-gallery.png)

| 按键 | 按住 `Tab` 时的功能 |
| --- | --- |
| `h` / `l` | 上一页 / 下一页 |
| `k` / `j` | 向前 / 向后移动三页 |
| 松开 `Tab` | 确认选中页面并聚焦正文 |
| `Esc` | 取消并恢复进入前的阅读位置和焦点 |

短按不带修饰键的 `Tab` 则切换区域焦点。退出画廊会保留目录原来的显示状态。`Shift-Tab` 和文本控件中的 Tab 保持原生行为。

## 搜索和选择文本

![PDF 搜索、匹配高亮与结果计数](images/vellum-search.png)

按 `/` 输入关键词，再按 `Enter` 确认。离开搜索框后，匹配结果仍保持高亮。

| 按键 | 功能 |
| --- | --- |
| `/` | 打开搜索框 |
| `Enter` | 确认搜索 |
| `n` / `N` | 下一个 / 上一个匹配 |
| `v` | 将当前匹配转为文本选择 |
| `y` | 复制选中文本或当前搜索匹配 |
| `Esc` | 离开搜索或清除可见搜索状态 |

可以用鼠标选择文本，也可以对搜索结果按 `v`。存在文本选择时，`h` / `l` 横向调整选择端点，`j` / `k` 按视觉行移动端点，`w` / `b` / `e` 按单词移动。按 `Esc` 清除选择后，恢复普通页面移动。

## 高亮和保存

从标签栏的圆形色块选择颜色，或按 `c` 在黄色、绿色、青色、紫色和粉色之间切换。

| 按键 | 功能 |
| --- | --- |
| `m` | 高亮选中文本 |
| `c` | 切换高亮颜色 |
| `y` | 复制选择 |
| `d` | 删除与文本选择相交的高亮 |

批注在后台自动保存到 PDF。如果保存失败或磁盘上的文件发生变化，Vellum 会保留内存中的批注，提供**重试**或**另存副本**。关闭标签页或退出应用之前，会等待待保存的更改完成保存或另存。

## 实验性 AI

AI 功能仍处于探索阶段，交互流程和回答质量还在评估与改进中。它是可选的实验性功能，以下内容作为当前实现的技术参考保留。

阅读、搜索和高亮无需配置 AI。按 `Command-,` 打开设置，配置服务。

1. 在 **AI 服务商**中选择预设或自定义 OpenAI 兼容端点。HTTP 服务使用 Base URL 和 API Key；Anthropic 使用 Messages API 格式。
2. 使用 **Codex** 预设时，填写已安装且已登录的 Codex CLI 可执行文件路径，可选填写配置档案。这一本地集成方式沿用 Codex 已有的身份验证，不使用在 Vellum 中填写的 HTTP API Key。
3. 在 **AI 解释**和 **AI 对话**中分别选择服务和模型。服务支持时可以获取模型列表，再通过测试端点（HTTP）或测试 Codex 检查配置。本地 Codex 的模型字段可留空，使用其配置中的默认模型。
4. 选择目标输出语言，也可以分别定制提示词模板。AI 输出语言与 Vellum 的中英文界面设置相互独立。

AI 请求会包含选中文本，以及从 PDF 提取的邻近上下文，例如页码、目录标题和前后段落，并发送到配置的服务。“本地 Codex”表示本地集成方式，其所选模型仍可能调用远程服务。

### 操作与保存

| 按键 | 阅读区中的功能 |
| --- | --- |
| `a` | 解释选中文本或选中的高亮 |
| `i` | 围绕选中文本或高亮开始对话 |
| `A` | 浏览当前 PDF 的解释历史 |
| `I` | 浏览当前 PDF 的对话历史 |

双击文本可以触发解释或翻译，初始默认启用，可在通用设置中调整。中键点击选中文本也可以触发解释。

解释窗口中，`j` / `k` 滚动内容，`c` 选择高亮颜色，`m` 将原文和回答一起保存为 PDF 高亮，`Esc` 关闭解释。悬停到已保存解释的高亮上，可以再次查看回答。

单词或短术语的解释可以包含发音和翻译。AI 解释设置还提供可选的自动发音，支持美式或英式英语声音。

对话中，输入追问后按 `Enter` 发送，`Shift-Enter` 换行，`Esc` 关闭对话。对话和未保存的解释保留在本次应用会话中；保存到高亮的回答嵌入 PDF，重新打开文件后仍可查看。

## 设置和更新

**通用**包含界面语言、标签恢复、默认打开方式、初始页面适配、高亮默认颜色、双击翻译、更新检查和 AI 日志。**AI 服务商**、**AI 解释**和 **AI 对话**配置 AI，**快捷键**提供应用内的按键参考。

更新由 Sparkle 处理，自动检查初始默认启用。新版本会在后台下载并准备。准备完成后，选择**重启并更新**立即安装，或选择**稍后**继续阅读；已准备好的更新也可以在正常退出 Vellum 时安装。在通用设置或 Vellum 菜单中手动检查，也使用同一个更新窗口。

简短状态使用随内容调整宽度的紧凑窗口，绿色勾表示 Vellum 已是最新版本。过长的更新说明使用较宽但受限的阅读区，滚动条隐藏，操作按钮始终可见。按钮字母不区分大小写，只作用于当前显示的操作。

| 按键 | 更新窗口中的功能 |
| --- | --- |
| `j` / `k` | 向下 / 向上滚动，支持次数，例如 `10j` |
| `gg` / `G` | 更新说明的开头 / 末尾 |
| `Control-D` / `Control-U` | 向下 / 向上滚动半个视口 |
| `Control-F` / `Control-B` | 向下 / 向上滚动一个视口 |
| `U` | 下载更新 |
| `R` | 重启并更新，或在出错后重试 |
| `L` | 稍后 |
| `C` | 取消或关闭，以按钮提示为准 |
| `O` | 打开发布页面 |
| `Tab` / `Shift-Tab` | 聚焦下一个 / 上一个按钮 |
| `Enter` | 执行获得焦点的按钮；没有按钮获得焦点时执行主要操作 |

AI 诊断日志位于 `~/Library/Application Support/Vellum/Logs/ai-requests.jsonl`，可以在通用设置中打开或清空。日志包含请求和回答片段，可能包含文档文本；凭据请求头会脱敏。提交问题时，先检查准备分享的日志内容。

## 常见问题

- **按键控制了其他区域：**快捷键跟随焦点。点击 PDF 控制正文，点击目录控制条目，按 `Esc` 关闭临时浮层。在搜索或对话输入框中，字母用于输入文字。
- **外部修改后的 PDF 仍显示旧内容：**通过文件选择器或 Finder 重新打开，并处理待保存的批注提示，使应用能够读取磁盘上的最新内容。
- **目录没有条目：**PDF 可能没有内置目录。
- **搜索或选择遗漏文字：**扫描页面或特殊文字编码可能使 PDFKit 无法提取文本。搜索和 AI 选择功能依赖可提取的文字。
- **AI 请求失败：**检查服务、端点或可执行文件、身份验证和模型，使用测试端点或测试 Codex，并查看诊断日志中的具体错误。

通过 [GitHub Issues](https://github.com/AbyssSkb/Vellum/issues) 提交问题和功能建议。请附上复现步骤、macOS 版本、Vellum 版本，以及可公开分享的示例 PDF（如适用）。
