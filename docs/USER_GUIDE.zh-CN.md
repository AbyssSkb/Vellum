# Vellum 使用文档

简体中文 | [English](USER_GUIDE.md) · [README](../README.zh-CN.md)

Vellum 是一款原生 macOS PDF 阅读器，支持键盘导航、沉浸画廊、可搜索的标签切换器、目录和高亮。要求 macOS 15 或更新版本，支持 Apple silicon 和 Intel Mac。

![Vellum 阅读界面](images/vellum-reader.png)

## 打开文件和管理标签页

从 [GitHub Releases](https://github.com/AbyssSkb/Vellum/releases/latest) 下载应用，打开磁盘映像，将 Vellum 拖入 Applications。启动后按 `o` 打开 PDF。

`Command-O` 和未选中文字时的 `o` 遵循**设置 → 通用 → 默认打开方式**，初始默认替换当前标签页。正文存在选区时，`o` 切换正在调整的选区端点，`Command-O` 仍可打开 PDF。`O` 在新标签页打开 PDF，支持一次选择多个文件。通过 Finder 打开的文件也会进入新标签页。

同一文件只保留一个标签页。再次打开时会选中已有标签；如果文件已在磁盘上更新，会在保护未保存批注之后重新读取最新内容。`X` 会从磁盘恢复最近关闭的 PDF。

| 按键 | 功能 |
| --- | --- |
| `o` / `Command-O` | 按配置的默认方式打开文件（`o` 需要未选中文字） |
| `O` | 在新标签页打开 PDF |
| `Z`（`Shift-Z`） | 模糊搜索主目录内已索引 PDF 的文件名和路径 |
| `x` / `Command-W` | 关闭当前标签页 |
| `X` | 恢复最近关闭的 PDF |
| `H` / `L` | 上一个 / 下一个标签页 |
| `[` / `]` | 上一个 / 下一个标签页 |
| `gT` / `gt` | 在阅读区切换到上一个 / 下一个标签页 |
| `Command-[` / `Command-]` | 上一个 / 下一个标签页 |
| `T` | 打开可搜索的标签切换器 |

在标签切换器中，输入文件名片段筛选列表。用 `↑` / `↓` 或单击列表项，预览该文档上次阅读的页面。按 `Enter`、点击选中页面的预览，或双击列表项切换文件。`Esc` 返回原文档和原来的焦点。此时字母用于搜索输入。

长标题会在打开文件或切换到该标签时滚动一轮，也可以悬停再次查看。通用设置中的**恢复上次标签页**可在下次启动时恢复阅读会话，初始默认关闭。

### 快速打开 PDF

在正文、目录或空窗口中按 `Z`（`Shift-Z`），或选择**文件 → 快速打开 PDF**。输入文件名或目录路径的片段，搜索当前用户主目录（`~/`）下 Spotlight 已索引、扩展名为 `.pdf` 的文件，兼容 `.PDF`。用 `↑` / `↓` 选择结果，`Enter` 按配置的默认打开方式打开文件，`Esc` 关闭浮层并恢复焦点。结果显示文件名与所在目录，不搜索 PDF 正文。

快速打开需要本机已安装 [fzf](https://github.com/junegunn/fzf)。使用 Homebrew 时运行 `brew install fzf`。Vellum 会检查常见 Homebrew 安装位置和应用继承的 `PATH`。找不到 fzf 时，浮层会显示安装提示，并提供**打开 PDF**按钮进入系统文件对话框。

Vellum 在后台收集 Spotlight 文件清单并缓存在内存中。启动后第一次搜索时，清单可能仍在加载，搜索框可以继续输入。Spotlight 索引变化后会更新清单。要搜索受保护的文件夹，在快速打开中选择**文件夹访问… → 文稿、下载或桌面**，并允许 macOS 访问；授权后会立即刷新清单。若曾拒绝访问，请在**系统设置 → 隐私与安全性 → 文件与文件夹**中开启权限后重试。新下载或移动的 PDF 可能需要等待索引，被 Spotlight 排除的文件可能不在结果中；需要时可用 `Command-O` 直接打开文件。

## 导航和缩放

短按移动页面；按住滚动键或缩放键，会持续移动或缩放。

| 按键 | 阅读区中的功能 |
| --- | --- |
| `j` / `k` | 向下 / 向上平滑滚动 |
| `d` / `u` | 大幅向下 / 向上滚动 |
| `D` / `U` | 更大幅度向下 / 向上滚动 |
| `h` / `l` | 向左 / 向右横向滚动 |
| `Space` / `f` | 向后翻一页 |
| `b` | 向前翻一页 |
| `gg` / `G` | 第一页并贴合文档顶部 / 最后一页并贴合文档底部 |
| `[数字]G` / `[数字]gg` | 跳到指定页，例如 `12G` 或 `12gg` |
| `Control-O` / `Control-I` | 在跳转历史中后退 / 前进 |
| `=` / `+` / `-` | 放大 / 缩小 |
| `0` | 适合整页 |
| `z` | 适合宽度 |

页面跳转和目录跳转都会进入跳转历史。数字页码按 PDF 中从 1 开始的页面位置计算。适配时保持页面比例：`z` 撑满阅读区宽度，`0` 保证整页可见。通用设置可以选择打开文件时适合宽度或适合整页。

正文移动支持次数：`10j` 向下滚动十步，`5f` 向后翻五页，`3n` / `3N` 前进／后退三个搜索结果。翻页到首页或末页时停止，搜索结果循环切换。存在选区时，`3w` 连续执行三次单词移动，`h` / `j` / `k` / `l` / `b` / `e` 也支持次数。带次数的命令执行一次，每次最多 1,000 步；不带次数的滚动键仍可按住。`Esc` 清除待完成的次数，`12G` / `12gg` 仍表示跳到指定页。

### 打开 PDF 链接

在正文中按 `F`，为当前可见的链接显示字母标签。输入标签打开链接，`Backspace` 修改尚未输完的标签，`Esc` 取消，`Enter` 打开剩余的第一个链接。文内链接会记录阅读位置，可用 `Control-O` 返回；网页链接交给系统的 URL 处理程序打开。滚动、调整窗口大小或缩放会取消标签。此功能使用 PDF 内嵌链接，不能识别没有链接的普通引用文字。当前没有可见链接时，会短暂显示提示，其他快捷键可以继续使用。

### 预览参考

按 `p`，为当前可见、且目标有效的内部链接显示标签。输入标签打开并聚焦浮动预览，正文的阅读位置和文本选区保持不动。`Backspace` 修改尚未输完的标签，`Enter` 预览剩余的第一个目标，`Esc` 取消标签。当前没有目标有效的可见内部链接时，会短暂提示原因，正文仍可接收其他快捷键。预览随正文可用宽高增大或缩小，保留内容比例和窄边框，采用内层圆角，不显示工具栏。

| 链接预览获得焦点时的按键 | 操作 |
| --- | --- |
| `j` / `k` | 向下 / 向上滚动预览 |
| `h` / `l` | 向左 / 向右滚动预览 |
| `d` / `u`、`f` / `b` | 大幅滚动预览 |
| `=` / `+` / `-` | 放大 / 缩小预览 |
| `p` / `Enter` | 关闭预览并将正文跳转到目标；`Control-O` 可返回来源位置 |
| `x` | 关闭预览并将焦点交回正文 |
| `Esc` | 关闭预览，继续阅读原位置 |

链接预览需要 PDF 内嵌且目标位于当前文档的内部链接，不能预览网页链接或普通引用文字。

内部链接预览会在文字和排版能提供可靠边界时，提取对应的目标区域：

- 图片包含相邻子图、紧邻图面的独立图例和对应图注。明确引用 `1(a)` 这样的子图时，原生标签和图形边界能确定归属就单独显示该子图及说明；归属不明确时保留整图。
- 表格包含标题、附属注释和完整边框，支持标题位于表格上方或下方。
- 带编号且有框线的算法包含标题、输入条件、步骤和旁注。
- 带编号的公式按引用编号匹配。`2` 这样的无后缀引用包含对应的 `2a` / `2b` 公式组；明确引用 `2a` 时只预览该公式。
- 带编号或采用悬挂缩进的参考文献，按完整条目裁切。无年份的作者引用支持 `a` / `b` 标记和 `n.d.`。
- 章节包含标题和开头段落，也支持目标指向相邻页面的目录链接。导语引出的列表和紧凑分栏列表，可在原生字体、对齐能确定边界时包含完整续文；其他文字目标在能定位独立段落时显示该段落。

引用中的 `Figure` 和 `Section` 支持在行末以连字符断开。完整区域适配到可用预览空间。未识别的目标和没有可读文本层的扫描页显示目标位置附近的页面内容。脚注在目标附近有可读标记，且分隔线或小字号文字能确定边界时，可单独预览。尚未分类的数字链接，包括没有框线的算法和定理引用，保留目标页面上下文。所有无法可靠定位精确边界的目标均保留页面上下文，包括边界不明确或与邻栏重叠的文献条目。

自动提取依据 PDF 文字和几何排版，不使用 AI 或 OCR。参考文献条目和章节开头段落可将相邻两页中已识别的片段合并预览。框线清晰的长表格可连接匹配的后续页面，其他区域通常保留在单页内。图片预览需要可读图号和独立的图形边界。文字、图注、表注和边框依据字号、间距、对齐及框线延续关系组成完整对象，再计算裁切范围。紧邻表格的小字号注释不要求有固定前缀。同字号且没有标记的注释，以及缺少清晰分隔的特殊排版，可能混入附近正文或遗漏续行。

## 浏览目录

按 `t` 显示或隐藏目录。打开时聚焦目录，并将浏览光标对齐到当前阅读章节；关闭时聚焦正文。短按不带修饰键的 `Tab` 在正文和目录之间切换焦点，目录隐藏时会先打开它。仅切换焦点会保留目录的显示状态和浏览光标。

选择条目后按 `Enter` 跳转并聚焦正文。目录中的 `Esc` 会先清除待完成的次数或命令前缀；没有待完成输入时，则回到正文焦点，目录仍然显示。也可以点击相应区域切换焦点。

当前阅读章节的标记与目录浏览光标相互独立。滚动时以阅读区域的水平中线判断当前章节，通常在章节标题越过这条线时更新。正文获得焦点时，进入另一个章节会让目录光标跟随该章节；目录获得焦点时，浏览光标、滚动位置和折叠状态由你控制，阅读章节标记可以独立更新。章节位于收起的分支内时，会标记最近的可见祖先，保留原有折叠状态。

![目录侧边栏和文件标签页](images/vellum-outline-tabs.png)

| 按键 | 目录获得焦点时的功能 |
| --- | --- |
| `j` / `k` 或 `↓` / `↑` | 下一个 / 上一个可见条目 |
| `h` 或 `←` | 关闭包含光标的一层折叠，等同于 `zc` |
| `l` 或 `→` | 打开包含光标的一层关闭折叠；没有可打开的折叠时向下移动一项 |
| `gg` / `G` 或 `Home` / `End` | 第一个 / 最后一个可见条目 |
| `[数字]G` / `[数字]gg` | 选择第几个可见条目 |
| `d` / `u` | 向下 / 向上移动半个目录视口 |
| `D` / `U`、`f` / `b`、`Page Down` / `Page Up` | 向下 / 向上移动一个视口 |
| `Space` | 向下移动一个视口 |
| `Enter` | 跳到选中条目的位置并聚焦正文 |
| `H` / `L` 或 `[` / `]` | 上一个 / 下一个文件 |
| `Control-O` / `Control-I` | 在 PDF 跳转历史中后退 / 前进 |
| `Tab` | 聚焦正文，目录仍然显示 |
| `Esc` | 清除待完成的次数或前缀，否则聚焦正文 |
| `t` | 关闭目录并聚焦正文 |

目录移动支持次数前缀：`10j` 从当前位置向下移动十个可见条目；`10G` 直接选择第十个可见条目。条目右侧的页码表示 PDF 跳转目标。

### 折叠目录

Vellum 使用 Vim 的折叠命令。按顺序输入按键，注意字母大小写。

| 命令 | 功能 |
| --- | --- |
| `zo` | 打开包含光标的一层关闭折叠 |
| `zc` | 关闭包含光标的最内层打开折叠 |
| `zO` | 打开包含光标的第一个关闭折叠及其所有后代 |
| `zC` | 关闭所有包含光标的折叠 |
| `zr` / `zm` | 增加 / 减少全局可见折叠层级 |
| `zR` / `zM` | 展开 / 折叠全部 |

次数放在 **`z` 前面**：`2zo` 最多打开两层包含光标的折叠，`2zc` 最多关闭两层，`2zr` / `2zm` 将全局层级增减两层。`zO`、`zC`、`zR`、`zM` 已经执行递归或全局操作，次数不会扩大其范围。

关闭包含光标的折叠后，应用仍记住光标原来的条目，即使可见选中项变成了祖先。接着按 `zo`，可以重新显露原来的条目。选中叶子条目时，`zc` 会关闭包含它的分支。局部折叠保留隐藏后代的展开状态；`zr`、`zm`、`zR`、`zM` 则对整个目录应用层级。切换文件时，每个打开的标签页会记住自己的目录状态。

`Option-→` / `Option-←` 递归展开 / 折叠当前分支。选中叶子时使用其父分支。再加 `Shift`，会应用到整个目录。

## 使用沉浸画廊

在正文或目录中长按不带修饰键的 `Tab`，在画廊中预览选中页及其相邻页面。

![沉浸画廊](images/vellum-gallery.png)

| 按键 | 按住 `Tab` 时的功能 |
| --- | --- |
| `h` / `l` | 上一页 / 下一页 |
| `k` / `j` | 向前 / 向后移动三页 |
| 松开 `Tab` | 确认选中页面并聚焦正文 |
| `Esc` | 取消并恢复进入前的阅读位置和焦点 |

短按不带修饰键的 `Tab` 则切换区域焦点。退出画廊会保留目录原来的显示状态。`Shift-Tab` 和文本控件中的 Tab 保持原生行为。

## 搜索和选择文本

![PDF 搜索、匹配高亮与结果计数](images/vellum-search.png)

按 `/` 输入关键词，再按 `Enter` 确认。离开搜索框后，匹配结果仍保持高亮。

| 按键 | 功能 |
| --- | --- |
| `/` | 打开搜索框 |
| `*` | 立即搜索选中文字 |
| `Enter` | 确认搜索 |
| `n` / `N` | 下一个 / 上一个匹配 |
| `v` | 将当前匹配转为文本选择 |
| `y` | 复制选中文本或当前搜索匹配 |
| 有选区时 `o` | 切换正在调整的选区端点 |
| 有选区时 `^` / `$` | 将端点移到视觉行首个非空白字符／行尾 |
| `gv` | 恢复上次文本选区及正在调整的端点 |
| `Esc` | 离开搜索或清除可见搜索状态 |

可以用鼠标选择文本，也可以对搜索结果按 `v`。存在文本选择时，`h` / `l` 横向调整选择端点，`j` / `k` 按视觉行移动端点，`w` / `b` / `e` 按单词移动。细光标标明正在调整的端点。按 `o` 切换到另一端继续调整，选区范围保持不变。`^` 将端点移到所在视觉行的首个非空白字符，`$` 移到行尾；这两个操作忽略次数前缀。`0` 仍然适合整页。按 `Esc` 清除选择后，恢复普通页面移动。

清除选区、高亮或用 `*` 搜索后，按 `gv` 恢复上次非空文本选区，原有范围和正在调整的端点都会恢复，可继续调整。每份已打开的文档分别记住选区；关闭或重新载入文档后清除这份记录。

按 `*` 直接搜索选中的单词或短语，无需打开搜索框。搜索不区分大小写，标点按原文匹配。匹配限定在单页内，跨页短语不会命中。原选区会清除，恢复页面移动；用 `n` / `N` 切换匹配，按 `v` 选中当前匹配。没有选中文字时，短暂提示会说明无法开始搜索的原因。

### 定位可见单词

1. 正文获得焦点时，按 `s`，输入屏幕内某个单词的开头，匹配不区分大小写。
2. 匹配的单词旁会显示字母标签。输入目标的标签，选中整个单词。多字母标签按顺序输入；输入过程中标签的位置和大小保持稳定。
3. 使用 `h` / `j` / `k` / `l` 或 `w` / `b` / `e` 调整选区，按 `y` 复制或按 `m` 高亮。

![通过可见单词旁的字母标签进行键盘选择](images/vellum-word-jump.png)

标签随文字的显示大小调整，并避开可能继续输入单词前缀的字母。匹配过密时，继续输入单词以缩小范围。

| 定位期间的按键 | 功能 |
| --- | --- |
| `Backspace` | 删除刚输入的标签字母；没有标签输入时，删除单词前缀的最后一个字符 |
| `Enter` | 选中剩余匹配中的第一个单词 |
| `Esc` | 取消定位，保留原有文本选择 |

单词定位依赖 PDF 中可提取的文字。扫描页面需要文字层才能定位单词。

## 本地词典

在 PDF 中选中单词后按 `K`（`Shift-K`）查词，小写 `k` 继续用于滚动或调整选区。也可以在**设置 → 通用**中将文本双击用途设为**词典**。词条在浮层中打开，保留原词典的 HTML 排版、样式、图片和本地脚本交互。点击词条内的单词链接可以继续查词。

### 配置词典

1. 将 `.mdx`、对应的 `.mdd` 资源文件和外置 CSS、JavaScript 文件放在同一个文件夹中。`dictionary.1.mdd` 等编号分卷也要与 `dictionary.mdd` 放在一起。
2. 打开**设置 → 通用**，选择本地词典的 `.mdx` 文件。未指定文件时，Vellum 也会自动检查 `~/Documents/Dictionary`。macOS 提示文件夹访问权限时，允许读取词典所在文件夹。
3. 选中单词后按 `K`；双击用途为**词典**时，也可以直接双击单词。

Vellum 直接从磁盘读取词典。首版支持未加密的 MDict 2.x 文件，文字编码为 UTF-8 或 UTF-16，数据块可不压缩或使用 zlib 压缩。暂不支持其他版本、编码、加密词库和 LZO 压缩。一次使用一部词典，应用不附带词库。

### 发音与双击用途

自动发音默认开启，优先播放词典中的美式录音。可在通用设置中改为英式发音，或关闭自动发音。自动播放需要可识别的英美词头发音链接；采用其他排版的词条仍可手动点击发音链接。词条原有的英式／美式扬声器链接播放对应的本地录音，不受自动发音偏好影响。

按 `Esc` 或点击外部关闭浮层；离开阅读器窗口时会停止发音并关闭浮层。

浮层打开时，`j` / `k` 上下滚动，`h` / `l` 左右滚动，`d` / `u` 移动半个视口，`f` / `b` 移动一个视口，`Space` 向下移动一个视口，`gg` / `G` 跳到词条顶部／底部。这些按键在浮层打开时控制词典页面。

词典页面和发音均在本地读取。Vellum 会阻止远程资源，因此需要网站或在线语音服务的功能不可用。播放需要资源文件中已有的录音；没有正式录音的句子可能需要额外的例句或 TTS 资源包。缺少配套文件也可能影响词条排版或交互。

文本双击用途可选**词典**、**AI**和**关闭**。新安装默认使用**词典**；升级时，旧版“双击翻译”中明确保存的选择会保留为 **AI** 或**关闭**。无论选择哪种双击用途，都可以用 `K` 查词，用 `a` 请求 AI 解释。

## 高亮和保存

从标签栏的圆形色块选择颜色，或按 `c` 在黄色、绿色、青色、紫色和粉色之间切换。

| 按键 | 功能 |
| --- | --- |
| `m` | 高亮选中文本 |
| `c` | 切换高亮颜色 |
| `y` | 复制选择 |
| `d` | 删除与文本选择相交的高亮 |
| `M` | 搜索当前 PDF 的高亮 |
| `gn` / `gN` | 按文档顺序选中下一条／上一条高亮 |

高亮列表同时包含普通高亮和保存了 AI 回答的高亮。输入原文或页码筛选，用 `↑` / `↓` 选择，按 `Enter` 跳到原文，`Esc` 返回此前的焦点。选中的原文支持已有的 `y`、`a`、`i`、`d` 操作。没有可提取文字的高亮仍可定位，文字操作需要 PDF 文字层。

批注在后台自动保存到 PDF。如果保存失败或磁盘上的文件发生变化，Vellum 会保留内存中的批注，提供**重试**或**另存副本**。关闭标签页或退出应用之前，会等待待保存的更改完成保存或另存。

## 实验性 AI

AI 是可选的实验性功能。按 `Command-,` 打开设置，配置服务。

1. 在 **AI 服务商**中选择预设或自定义 OpenAI 兼容端点。HTTP 服务使用 Base URL 和 API Key。
2. 使用 **Codex** 预设时，填写已安装且已登录的 Codex CLI 可执行文件路径。Vellum 使用 CLI 已有的身份验证。使用 Codex CLI 0.162.1 时，将 **Codex 配置档案**留空。
3. 在 **AI 解释**和 **AI 对话**中分别选择服务和模型。用**获取模型**查看可选项，再通过**测试模型**验证配置。本地 Codex 的模型字段可留空，使用 CLI 配置中的默认模型。
4. 使用 Codex 时，可以分别设置解释和对话的**思考深度**。解释默认使用**中**，对话默认使用**高**，两个页面各自记住你选择的档位。可选档位来自 Codex 的模型列表；用**获取模型**刷新选项。
5. 选择目标输出语言，也可以分别定制提示词模板。AI 输出语言与 Vellum 的中英文界面设置相互独立。

AI 请求将选中文本及从 PDF 提取的邻近上下文，例如页码、目录标题和前后段落，发送到配置的服务。通过本地 Codex CLI 使用的模型可能调用远程服务。

### 操作与保存

| 按键 | 阅读区中的功能 |
| --- | --- |
| `a` | 解释选中文本或选中的高亮 |
| `i` | 围绕选中文本或高亮开始对话 |
| `A` | 浏览当前 PDF 的解释历史 |
| `I` | 浏览当前 PDF 的对话历史 |

在通用设置中将文本双击用途设为 **AI**，即可通过双击触发解释或翻译。中键点击选中文本也可以触发解释。

解释窗口中，`j` / `k` 滚动内容，`c` 选择高亮颜色，`m` 将原文和回答一起保存为 PDF 高亮，`Esc` 关闭解释。悬停到已保存解释的高亮上，可以再次查看回答。

单词或短术语的解释可以包含发音和翻译。AI 解释设置还提供可选的自动发音，支持美式或英式英语声音。

对话中，输入追问后按 `Enter` 发送，`Shift-Enter` 换行，`Esc` 关闭对话。对话和未保存的解释保留在本次应用会话中；保存到高亮的回答嵌入 PDF，重新打开文件后仍可查看。

## 设置和更新

**通用**包含界面语言、标签恢复、默认打开方式、初始页面适配、高亮默认颜色、本地词典与发音设置、文本双击用途、更新检查和 AI 日志。**AI 服务商**、**AI 解释**和 **AI 对话**配置 AI，**快捷键**提供应用内的按键参考。

操作反馈统一显示为窗口顶部的 Toast，几秒后自动消失，保留当前键盘焦点，可以继续阅读或输入。检查更新的结果也使用同样的提示；出错时可点击查看详情。正在进行的更新和标注保存恢复仍保留操作窗口，方便完成或处理。

快捷键未生效时，Toast 会说明原因，例如未选中文字、选区内没有高亮、没有搜索词或跳转历史。复制成功会短暂确认。重复触发同一条提示不会延长其显示时间。文件打开、恢复和重新载入失败会显示文件名及可确认的原因；批量失败合并显示，长消息的完整内容可通过悬停提示或辅助功能读取。

更新由 Sparkle 处理，自动检查初始默认启用。新版本会在后台下载并准备。准备完成后，选择**重启并更新**立即安装，或选择**稍后**继续阅读；已准备好的更新也可以在正常退出 Vellum 时安装。在通用设置或 Vellum 菜单中手动检查，也使用同一个更新窗口。选择**更新并重启**后，应用会连续完成下载、安装和重启。重启前会保存标注和阅读会话。

带绿色勾的 Toast 表示 Vellum 已是最新版本。用下方按键滚动过长的更新说明，操作按钮始终可见。按按钮上标出的字母即可执行操作，大小写都有效。

| 按键 | 更新窗口中的功能 |
| --- | --- |
| `j` / `k` | 向下 / 向上滚动，支持次数，例如 `10j` |
| `gg` / `G` | 更新说明的开头 / 末尾 |
| `Control-D` / `Control-U` | 向下 / 向上滚动半个视口 |
| `Control-F` / `Control-B` | 向下 / 向上滚动一个视口 |
| `U` | 下载、安装并重启 |
| `R` | 重启并更新，或在出错后重试 |
| `L` | 稍后 |
| `C` | 取消或关闭，以按钮提示为准 |
| `O` | 打开发布页面 |
| `Tab` / `Shift-Tab` | 聚焦下一个 / 上一个按钮 |
| `Enter` | 执行获得焦点的按钮；没有按钮获得焦点时执行主要操作 |

AI 诊断日志位于 `~/Library/Application Support/Vellum/Logs/ai-requests.jsonl`，可以在通用设置中打开或清空。日志包含请求和回答片段，可能包含文档文本；凭据请求头会脱敏。提交问题时，先检查准备分享的日志内容。

## 常见问题

- **按键控制了其他区域：**快捷键跟随焦点。点击 PDF 控制正文，点击目录控制条目，按 `Esc` 关闭临时浮层。在搜索或对话输入框中，字母用于输入文字。
- **外部修改后的 PDF 仍显示旧内容：**通过文件选择器或 Finder 重新打开，并处理待保存的批注提示，使应用能够读取磁盘上的最新内容。
- **目录没有条目：**PDF 可能没有内置目录。
- **搜索或选择遗漏文字：**扫描页面或特殊文字编码可能使 PDFKit 无法提取文本。搜索和 AI 选择功能依赖可提取的文字。
- **找不到词条或无法发音：**检查选中的 `.mdx` 文件，并将配套资源放在一起。词典可能没有收录该单词，发音也需要本地已有的录音。远程资源始终不会加载。
- **AI 请求失败：**检查服务、端点或可执行文件、身份验证和模型，使用测试端点或测试 Codex，并查看诊断日志中的具体错误。
